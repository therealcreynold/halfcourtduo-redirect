# halfcourtduo.com

The game Half Court Duo was renamed Hinge Hoops on 2026-10-27 (App Review guideline 5.2.5), and its
website moved to https://hingehoops.com (repository `halfcourtduo-website`). GitHub Pages serves one
custom domain per repository, so this one keeps halfcourtduo.com answering over https and sends every
page to its new address: the home page, `/privacy/` (the link compiled into TestFlight 1.0 (6) and named
in the AdMob consent message), `/support/` and `/terms/`; anything else lands on the new home page.
No JavaScript, no assets: a meta refresh and a canonical link on each page.
